The desk process

The point is not a national CAD dump. The point is a repeatable packet that can travel from a VFG project card to a council email to an engine question without mixing rooms.

1. Seed list

Use only parks VFG has already published, plus Windemere as the live bid object. Source: skateparkconstruction.com.au/projects.

2. Packet before file

Every artefact gets a sidecar before it is saved. Train stays no unless a written licence exists.

3. Public harvest

See Trail then Tasks for doors and letters.

4. Informal ask, then formal access

NSW GIPA, Victoria FOI, Queensland RTI. Inspection-only is still a useful fact.

5. Engine room

Cite acts you already hold. Do not invent section numbers.

6. Training gate

Facts and own scans can pass. Construction sets cannot until licensed.
