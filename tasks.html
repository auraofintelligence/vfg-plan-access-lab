Personal, then precise

Ask for a licence to learn from parks already built

A small named set of completed VFG and council parks so a licensed local model can help the next tender and the next maintenance job. Windemere is the live test.

Pattern A — VFG / Kieran

To: kieran@vfgskateparks.com.au
Subject: Licence to learn from parks we already built — Windemere and the public list

Hello Kieran,

I’m Luke — Strange But True on Minjerribah, working with you on Windemere Road Park in Redland City.

I’m putting together a small, named set of completed parks from the public VFG list so we can train a local model under a written licence. The job of that model is practical: faster responses on future tenders, cleaner maintenance and digital-twin work on parks already in the ground. Windemere is the live test. Black Head, Cowes, Bathurst and the 2018 Shellharbour rebuild are the first completed references.

I don’t want a dump of every file, and I won’t put construction sets on the open web or into an unlicensed training run.

What would help:

1. A short written licence (research + local model training for tender and maintenance support) covering as-constructed information for those four parks, and a path to add more from the unpublished list.
2. For each park: who designed, who built, year opened, and whether you or the council hold copyright in the WAE sheets.
3. The smallest useful package per park — WAE / as-constructed PDF, or a supervised extract of geometry and spec notes if full sheets can’t leave the office.

Windemere tender files stay in the bid room. This letter is only about learning from parks already built, so the next one is less guesswork.

Happy to jump on a call.

Luke Nathan Hayes
Strange But True
Amity, Minjerribah / North Stradbroke Island
iseeinfinity.com

Pattern B — council assets, one park

Subject: [PARK] at [RESERVE] — licence to use as-constructed records for maintenance and future design

Hello,

I’m Luke Nathan Hayes, Strange But True. I’m working with VFG Skateparks on the Windemere Road Park tender in Redland City, and I’m assembling a licensed reference set of completed skate facilities so we can plan maintenance and answer future tenders without rediscovering each park from scratch.

[RESERVE], [STREET], [TOWN] is on VFG’s public projects list as [PARK] ([YEAR if known]).

Could your assets or parks team help with:

1. Official reserve / asset name and year opened or last rebuilt.
2. Designer and builder, if held.
3. Whether as-constructed / works-as-executed drawings exist.
4. Whether Council can license those drawings (or a supervised extract) for a local research model used on tendering and maintenance — or whether copyright sits with VFG / the designer and I should take the licence talk there.
5. Inspection if a copy cannot be licensed. That is still useful.
6. Asset ID or GIS pin if published.

I am not asking to republish drawings, and I am not asking for other tenderers’ prices. If this belongs with Governance as an informal access request, send me to the form on [ACCESS PAGE URL] and I will use it.

Thanks for the time,
Luke Nathan Hayes

Pattern C — formal form text

Documents sought for the existing skate facility at [RESERVE], [STREET], [TOWN]:
- as-constructed / works-as-executed drawings and specifications
- award minute or report naming designer and builder
- grant or funding advice that names the program

I prefer inspection where a copy would infringe copyright. I seek a licence path for research and local-model training to support future tenders and maintenance, not republication of drawings and not other tenderers’ pricing.
