Personal, then precise

Ask for a licence to learn from parks already built

Named completed parks. Native CAD plus as-constructed sheets, under licence, to streamline future tenders and maintenance. Windemere is the live test.

  • Designer, builder, year, grant, reserve, asset ID.
  • WAE sheets and native CAD (DWG / DXF / 3D if held).
  • Written licence for local-model training. CAD stays in the licensed room.

Pattern A — VFG / Kieran

To: kieran@vfgskateparks.com.au
Subject: Licence to learn from parks we already built — including CAD

Hello Kieran,

I’m Luke — Strange But True on Minjerribah, working with you on Windemere Road Park in Redland City.

I’m putting together a small, named set of completed parks from the public VFG list so we can train a local model under a written licence. The job of that model is practical: faster responses on future tenders, cleaner maintenance and digital-twin work on parks already in the ground. Windemere is the live test. Black Head, Cowes, Bathurst and the 2018 Shellharbour rebuild are the first completed references.

I need the CAD in that licence, not only a PDF. I will not put construction sets on the open web or into an unlicensed training run.

What would help:

1. A short written licence (research + local model training for tender and maintenance support) covering as-constructed drawings and native CAD for those four parks, and a path to add more from the unpublished list.
2. For each park: who designed, who built, year opened, and whether you or the council hold copyright in the WAE sheets and CAD.
3. The useful package per park — native CAD (DWG / DXF / 3D model if it exists), WAE / as-constructed PDF, and a spec or set-out note. If full CAD cannot leave the office, a supervised extract of the geometry still helps.

Windemere tender files stay in the bid room.

Happy to jump on a call.

Luke Nathan Hayes
Strange But True
Amity, Minjerribah / North Stradbroke Island
iseeinfinity.com

Pattern B — council

Could your assets or parks team help with whether as-constructed drawings and native CAD (DWG / DXF / 3D) exist, and whether Council can license those CAD files for a local research model used on tendering and maintenance — or whether copyright sits with VFG / the designer.

Pattern C

Documents sought: as-constructed / WAE drawings, specifications, and native CAD (DWG / DXF / 3D if held); award minute; grant advice. Inspection if a copy would infringe copyright. Licence path for local-model training for tenders and maintenance. Not republication.
