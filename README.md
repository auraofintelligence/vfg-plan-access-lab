# VFG Plan Access Lab

Strange But True public-source demo of a **remote-first** process for collecting provenance around Australian skate park plans, starting from the parks listed on the VFG Skateparks public projects page.

It is not legal advice. It is not VFG's portfolio. It is not for construction. It does not ship drawings.

Live site (once Pages is on): https://auraofintelligence.github.io/vfg-plan-access-lab/

Public pages are static HTML. Open `index.html` locally or use GitHub Pages.

## What it demos

- Seed cabinet of 11 VFG-listed parks plus Windemere as the live Queensland object
- Six-step desk process (list to packet to public harvest to informal/RTI ask to legal engine to training gate)
- Interactive packet sidecar with a default `train: no` gate
