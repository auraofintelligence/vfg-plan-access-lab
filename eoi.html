Strange But True

Expression of Interest

Licensed use of completed-park CAD for local-model training

From

Luke Nathan Hayes trading as Strange But True
Amity, Minjerribah / North Stradbroke Island

To

VFG Skateparks
attention Kieran

Date: ____________________

1. Interest

I am interested in a working arrangement under which VFG names a first set of completed parks and provides as-constructed drawings and native CAD so Strange But True can train a local model for future tenders, set-out, maintenance and digital-twin work.

2. Suggested first parks

Black Head (Hallidays Point); Cowes; Bathurst; Shellharbour 2018 rebuild.

3. Files sought

Native CAD (DWG / DXF / 3D if held); as-constructed / works-as-executed PDF; designer; builder; year; who holds copyright.

4. Limits

Files stay off the public web. VFG keeps ownership. No on-sale of VFG designs. Windemere Road Park tender files stay in the bid room and are not part of this expression of interest.

5. Next step

If VFG is interested, we move to the short memorandum of understanding and then exchange files. Training does not start on an expression of interest alone.

Luke Nathan Hayes
Strange But True
Date ________
