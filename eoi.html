EXPRESSION OF INTEREST

From: Luke Nathan Hayes / Strange But True
Amity, Minjerribah / North Stradbroke Island
To: VFG Skateparks (Kieran)
About: licensed use of as-constructed drawings and CAD from completed VFG parks

I am interested in a working arrangement where:

1. VFG names a first set of completed parks (suggested: Black Head, Cowes, Bathurst, Shellharbour 2018).
2. VFG provides as-constructed PDFs and native CAD (DWG / DXF / 3D if held), or a time to copy them.
3. Strange But True trains a local model on those files for tendering, set-out, maintenance and digital-twin work.
4. Files stay off the public web. VFG keeps ownership. No on-sale of VFG designs.
5. Windemere Road Park tender files stay in the bid room and are not part of this EOI.

This EOI is not a contract and not a licence. If VFG is interested, we move to the short MOU and then exchange files.

Luke Nathan Hayes
